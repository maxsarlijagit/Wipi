# Changelog

## 0.3.0

- Tareas en curso y avisos de Claude Code CLI y sesiones locales de la pestaña Code en Claude Desktop.
- Conexión de hooks desde la bandeja de Wipi, con respaldo y preservación de los hooks previos.
- El hook de Claude envía solo metadatos de actividad por el puente local; no reenvía prompts ni respuestas.

## 0.2.0

- Panel con tareas de Codex en curso por proyecto, último paso y tiempo transcurrido.
- Barra arrastrable que recuerda su posición y menú para volver arriba al centro.
- Taza de café con vapor animado, contador de tareas y nuevo icono.
- Temas Graphite, Pearl, Violet, Mint y Sunset.
- Avisos de Codex Desktop y CLI; extensión opcional para avisos de ChatGPT web.

## 0.1.0

- Primera barra flotante para Windows con avisos recientes y bandeja del sistema.
