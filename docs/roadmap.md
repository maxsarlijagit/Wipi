# Ideas para próximas versiones

Estas son propuestas, **no funciones disponibles en Wipi 0.2.0**.

- Mostrar respuestas en curso de ChatGPT web sin depender de selectores frágiles.
- Explorar una integración compatible con ChatGPT Desktop si existe una fuente de eventos pública y estable.
- Permitir prioridades y reglas de silencio para muchos proyectos simultáneos.
- Abrir la tarea correspondiente al pulsar una tarjeta, cuando haya un enlace local verificable.
- Ofrecer controles compactos tipo Stream Deck sin saturar la barra.
- Añadir firma de código, actualizaciones y una distribución pública reproducible.

Antes de implementar una integración nueva, comprobar que la fuente de eventos existe, que no exige leer contenido sensible innecesario y que la interfaz distingue claramente lo confirmado de lo inferido.
