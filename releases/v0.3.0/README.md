# Wipi 0.3.0 for Windows

[English](#english) · [Español](#español)

## English

- Installer: [Wipi-Setup-0.3.0.exe](Wipi-Setup-0.3.0.exe)
- Platform: Windows x64
- Build: Electron 44.5.1, built from Wipi 0.3.0 on 2026-10-07
- Code signature: none
- SHA-256: see [SHA256SUMS.txt](SHA256SUMS.txt)

Run the installer and open Wipi from the Start menu. To connect Claude Code CLI and local sessions in Claude Desktop's **Code** tab, choose **Conectar Claude Code** in Wipi's tray menu, then start a new Claude session. See the [main README](../../README.md) for the other integrations and their limits.

The executable is tracked with Git LFS. If cloning the repository, install Git LFS and run `git lfs pull` to obtain it. For public downloads, attach the installer to the corresponding GitHub Release.

## Español

- Instalador: [Wipi-Setup-0.3.0.exe](Wipi-Setup-0.3.0.exe)
- Plataforma: Windows x64
- Compilación: Electron 44.5.1, generada desde Wipi 0.3.0 el 2026-10-07

Ejecutá el instalador y abrí Wipi desde el menú Inicio. Para conectar Claude Code CLI y las sesiones locales de la pestaña **Code** de Claude Desktop, elegí **Conectar Claude Code** en la bandeja de Wipi e iniciá una sesión nueva de Claude. El [README en español](../../README.es.md) explica las demás integraciones y sus límites.

El ejecutable se guarda con Git LFS. Si clonás el repositorio, instalá Git LFS y ejecutá `git lfs pull` para obtenerlo. Para descargas públicas, adjuntá el instalador a la GitHub Release correspondiente.
