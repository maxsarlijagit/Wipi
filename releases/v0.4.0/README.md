# Wipi 0.4.0 for Windows

[English](#english) · [Español](#español)

## English

- Installer: [Wipi-Setup-0.4.0.exe](Wipi-Setup-0.4.0.exe)
- Platform: Windows x64
- Build: Electron 44.5.1, built from Wipi 0.4.0 on 2026-10-07
- Code signature: none
- SHA-256: see [SHA256SUMS.txt](SHA256SUMS.txt)

Run the installer and open Wipi from the Start menu. This version labels local Work tasks from ChatGPT for Windows separately from Codex Desktop tasks, and alerts when a local turn is interrupted. Regular ChatGPT chats are outside the local session integration. See the [main README](../../README.md) for setup and limits.

The installer is tracked with Git LFS. If cloning the repository, install Git LFS and run `git lfs pull`. For public downloads, attach the installer to a GitHub Release.
